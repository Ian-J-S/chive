# Chive
## TUI Archive manager app

Allows you to visually build archive files from the terminal.
### Features:
- Create archives interactively
- Browse files from within the terminal
- Extract existing archives
- Adjustable compression levels
- Lightweight, keyboard-driven interface
- Supports multiple archive formats

### Supported file types:
7z ☑ \
zip ☑ \
tar.gz ☑ \
tar.xz ☑
